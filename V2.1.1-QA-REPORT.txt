MARKET DESK 2.1.1 — RELEASE VERIFICATION
3 November 2026

RESULTS
113 Python regression tests passed via tests/run_all.py.
12 JavaScript suites passed, including 25 new reliability checks.
All 13 website JavaScript files passed syntax parsing.
The Mac ZIP was checked for file integrity and executable launcher permissions.

The Python runner uses a temporary home and blocks outside network requests.
Local HTTP tests are allowed. Private user keys and market data are not part
of the release bundle. JavaScript tests use fake prices and a fake clock only
inside the test files; no example prices are added to the production website.

LIMITS
These checks do not prove live access for every stock on a user's provider
plan. Real Mac sleep/wake, long unattended use, and a complete Safari/browser
matrix were not exercised. Clock pauses and stale data were tested with
controlled fixtures. Planned refresh times remain estimates, not guarantees.
Older QA files in the source folder describe earlier releases only.

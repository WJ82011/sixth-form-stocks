# V3.0 release scope

Preserve all existing V2 tools and saved research. Local Mac ZIP delivery.

- [x] Portfolio accounting: FIFO, fees, deposits/withdrawals, dividends,
  explicit dated FX, splits, complete/partial valuations and exports.
- [x] Matched-date portfolio checkpoints and clearly labelled benchmark review.
- [x] Three-statement research, broader standard SEC concepts, IFRS/currency
  coverage where available, and separate source-linked manual statement rows.
- [x] Events calendar: SEC filing history, optional earnings access, manual
  confirmed/estimated events, revision history and calendar export.
- [x] More official macro series with actual observation periods.
- [x] Broader SEC listing search and saved-account fundamental screening.
- [x] Rebased chart comparison and optional source-qualified cap weighting.
- [x] Personal home layout, research handoff and complete V3 backup support.
- [x] Regression, accounting, source/coverage and responsive browser QA.

Unsupported data, access restrictions and missing records must remain visible.
No paid OpenAI, brokerage orders, invented prices or continuous-learning claims.

Coverage boundaries and future work are explicit in V3.0-METHODOLOGY.txt.

# Market Desk V3.9 verification

Verification took place on 9 November 2026 in a separate temporary workspace.
The release scope was inferred from the requested forecast and Live Tape work
because the local roadmap contained no distinct V3.9 checklist.

## Forecast

The visible curve starts at the last observed daily close. The right edge now
corresponds to the last scenario session. The focus view scales only the
centre and links directly back to the full uncertainty view.

The model retains the damped 5-, 20- and 60-session trend. With 160 or more
closes, it searches up to 750 earlier anchors for similar trends and volatility.
Matches are separated in time and their complete outcome windows precede the
current anchor. When at least eight matches qualify, the centre blends 35%
of a bounded median historical path with the base trend. Some historical
outcome windows may overlap. The surrounding fan is illustrative and has no
calibrated probability. Walk-forward tests call the same model with only the
prices available at each past anchor. Saved forecasts are analytical scenarios.

In the browser, AMD's saved closes produced a visible damped curve. Its
60-session detail showed a centre change of -1.41% in that observed test.
The full view was restored from the same control.

## Live Tape

The browser loaded 3,984 saved positive-size Apple trade records from 6
November. The selected one-hour window at the end showed 1,473 captured trades.
The UTC date selector and slider recovered both the earliest and latest
recorded times. Candle selection, table size filter, return to the rolling view
and direct Wingstop selection were exercised. The watchlist count stayed the
same when Wingstop opened. At 390 pixels wide, the page fit the viewport.

Tape candles and volume describe the sample captured by this Mac. They can
differ from exchange-wide candles and totals. The saved review reads local
records and its loaded sample stays fixed. Testing used actual saved prints
and a disposable database. Finnhub live connection behavior was checked in
fixtures for slot priorities and ingestion. The browser preview used a copy
of existing records, with the user's running app left alone.

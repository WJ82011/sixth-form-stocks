V6.4 CONNECTION CHECKLIST
14 November 2026. No optional language model is installed. Answers are local calculations.

SUPPORTED
- Chart: the return is the change between the two displayed prices.
- Crypto: a saved crypto forecast report can be explained. Asking does not write a new report.
- Heatmap, comparison, events and financials: Ask Intelligence carries the selected company and period.
- Forecast: “Has this forecast model beaten its baseline?” reads the check and does not save a new experiment. A learned status is shown only when the model error is smaller than an unchanged price.
- Alerts: a question does not arm an alert.
- Scan: “Why did this company match my scan?” uses the saved scan result.
- Portfolio: “Which holding contributed most?” uses a saved stress test. Mixed currencies are not ranked.
- Scenario: growth can be compared with the filing. An operating-margin assumption is not subtracted from net margin.
- Strategy, journal and reports: the button carries that area. A missing record is named.
- Investigation: “What changed since I saved this investigation?” says whether a later version exists. The original is kept.

CONFIRM BEFORE SAVING
A proposed change is stored only after confirmation. That copy does not arm an alert and does not edit a scenario number.

NOT CONNECTED TO A LANGUAGE MODEL

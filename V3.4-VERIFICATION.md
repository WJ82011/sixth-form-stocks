# V3.4 verification

V3.4 adds Analyst Lab inside Market Desk Intelligence, without adding sidebar
entries or replacing the earlier financial, chart, news, research or AI tools.

## Automated results

[V3.4-AUTOMATED-RESULTS.json](V3.4-AUTOMATED-RESULTS.json) records three passing
rounds of **434 Python tests**. These repeat the same suite; they are not 1,302
unique tests. [V3.4-JAVASCRIPT-RESULTS.json](V3.4-JAVASCRIPT-RESULTS.json) lists
**30 passing JavaScript test files**. All website scripts parse successfully.
Tests use disposable homes/databases and block real provider requests.

New cases cover price/volume interaction, partial affected revenue, variable
and fixed costs, launch timing/recognition/cannibalisation, required evidence,
no-double-count confirmation, unsupported cost classifications, missing and
nonfinite inputs, explicit capital/ADR assumptions, unavailable valuations,
three unique cases, source URL validation, immutable records, archive rules,
original-horizon review, backward-compatible backups and atomic corruption
rejection. Baselines supplied by a client cannot replace or silently change
saved SEC source inputs. Saved cases reach the local assistant as explicitly
conditional A1–A4 passages; scenario passages do not imply SEC authorship.

The price-model tests check training-label cutoffs, prefix invariance when
future data are appended, independently recomputed baseline errors, prior-only
residual coverage, stale-data withholding, aligned/missing benchmark behaviour,
duplicates, unsupported gaps/extreme moves, flat prices and current New York
session exclusion. Existing regression tests retain the earlier recovery,
accounting, source separation, concurrent writes, local request protections,
chart, project and import checks. A new interface regression guards against a
collision with the retained global navigation attribute.

## Browser checks

An isolated temporary server used copies of existing genuine public saved
provider/SEC/FRED records. Keys were redirected to missing temporary files;
no personal portfolio, notes, reports or private workspace was loaded into
that preview. Browser test records were explicitly labelled synthetic QA
assumptions and are excluded from the release. Existing source data was read
without modification.

- All **22 tool destinations** opened correctly at desktop and 390-pixel phone
  widths. The phone checks found no document-width overflow on any destination.
- Loaded Take-Two's actual saved annual statement baseline and its filing link.
  No future company sales or GTA assumptions were invented.
- Compared unchanged-business references and an explicitly fictional QA launch;
  the launch test recognised 15 million revenue and 12 million incremental
  operating profit under the supplied synthetic inputs. These are arithmetic
  test outcomes, not actual Take-Two estimates.
- Verified evidence entry, switching cases without losing entered inputs,
  invalidation of old results, immutable saves, JSON download, read-only frozen
  review after reload, archiving/restoring and retention of the correct page.
- Read saved news and economic context with actual source/observation dates.
  A provider's company list can contain irrelevant headlines; the UI says so.
- Ran the new price model against saved Take-Two history. Its error exceeded
  the unchanged-price baseline in that sample; negative skill was shown. No
  claim of a predictive advantage follows from this test.
- Inspected desktop/phone screenshots and the retained light appearance. The
  new panel uses existing theme/radius variables and respects reduced motion.

The original source data, private keys and earlier releases were preserved.
No paid service, new language-model weights or visual library was added.

## Boundaries

No new live-provider uptime guarantee, continuously running collector,
news-trained stock model, historical fundamental/news backtest, independently
verified user excerpt, AI semantic-accuracy score or Wall Street outperformance
claim is made. The existing local model is unchanged; new conditional evidence
is supplied to its retained grounded-answer path. This release does not infer
unavailable prices, FX, ADR ratios, market consensus or launch guidance.
Financial/business suitability and interpretation still need human review.

The Mac ZIP is checked for archive CRC, byte-for-byte agreement with packaged
source, executable launchers, absence of runtime databases/workspaces and
absence of the known local provider keys. See PACKAGE-SIZES.txt for size and
V3.4-QUICK-GUIDE.txt for opening instructions.

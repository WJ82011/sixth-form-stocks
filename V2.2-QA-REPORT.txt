TEST ISOLATION & LIMITS
The Python regression runner uses a temporary home and blocks outside network
requests while allowing localhost HTTP tests. Test prices are fixtures only.
No live user keys or personal price data are included in the release.
Actual live entitlement, long unattended use, real Mac sleep/wake and a complete
Safari/browser matrix were not verified. These checks do not guarantee that an
alert will catch every market move. Provider freshness rules may withhold triggers.

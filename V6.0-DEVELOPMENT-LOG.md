V6.0 DEVELOPMENT LOG
Written so the decisions can be explained without reading the code. 14 Nov 2026.

WHAT THE RELEASE IS
Market Desk stays a local Mac app. Prices, filings and candles come from the free feeds already connected: Finnhub, Massive Stocks Basic, the public Coinbase Exchange API, SEC company facts and FRED. No new paid service and no new installed library were added. The Python server and the browser files are part of this project. Provider terms still apply to their data.

THE INVESTIGATION PATH
A saved scan card opened the Overview page, and the chart function that keeps a date window was not available to the page. The move review then had nowhere visible to sit. The card now opens Home when the approved layout is on, and the chart keeps the scanned dates. The company box on Comparison, the simulator and the research pack follow the selected company when those boxes are empty or still show the previous company. Dates from the scan fill empty comparison dates.

Evidence: in the running app a saved scan titled “V6 investigation” matched ABNB with alerts left off. The card opened Home on ABNB. Move Review read US$181.13 on 2026-11-12 to US$186.78 on 2026-11-13, +3.12%, from saved Massive closes. SPY was not compared because a saved SPY close for that span was missing. Comparison with BKNG used the same two dates. ABNB has no saved SEC accounts and no saved events, so those sections stayed empty instead of being filled in. The five-session forecast had too little saved history and stayed insufficient. No scenario was calculated.

The journal entry “V6 investigation · ABNB move” keeps 186.78 and the two dates. Research pack edition 3 reopened without being rebuilt. It includes price history, the move, the saved ABNB 3.12% comparison with BKNG, and the journal entry. Events, financials, the scenario and the forecast stay omitted because those records are not there.

MEASUREMENTS ON THIS MAC
Before the collector change, the server log showed 10 collector polls in 6.01 seconds, 1.67 per second. Server memory was about 49 MB. After the change, this page recorded 0 collector polls in 6 seconds while it was not the focused document. The updated page waits 8 seconds when hidden, 3 seconds when idle, and 1 second when Live Tape is open or a trade arrives. The server log still showed about 1.2 polls per second because another Market Desk page was still using the old one-second loop.

The page navigation was 130 ms. Drawing the chart 40 times averaged 0.38 ms. Eight Standard/Professional switches averaged 2.95 ms and kept the company. Six ticker changes averaged 9.27 ms before the new chart request returned. The home page responded in 5 ms and Take-Two’s saved history in 4 ms. Importing the server code took 0.036 seconds. A long memory soak was not run. The short reading stayed near 48–49 MB and the collector still refuses a second start.

WHY THE MODELS WERE NOT CALLED STRONG
The five-session equity check uses only prices known at each decision, then scores a later block against an unchanged price. Take-Two: 500 closes, 34 later tests, model error 4.00 percentage points, unchanged 3.83, withheld. Apple: 500 closes, 34 tests, 2.92 against 2.81, withheld. JPMorgan: 500 closes, 34 tests, 1.73 against 1.75. The later block was slightly closer, but the earlier calibration block was not, so the forecast stayed withheld. That is the rule, not a leak. Exxon, Pfizer and NextEra have 11 saved closes here, so the check was insufficient. Bitcoin, Ethereum and Solana, 24-hour horizon, 581 candles, 144 later tests: the chosen weight was 0, so the model error equals the unchanged price (1.37, 1.80 and 2.06). The historical-average errors were higher. No forecast was issued. Nothing in this sample was strong enough to suggest the test had seen its own answers.
